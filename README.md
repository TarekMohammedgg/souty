# تطبيق صوتي | Souty - مسجل ومفرغ الصوت الذكي

<p align="center">
  <img src="src/assets/icon.svg" width="128" height="128" alt="Souty Icon" />
</p>

تطبيق سطح مكتب مبني بواسطة **Electron** لتسجيل الصوت وتفريغه نصياً بدقة عالية باللغتين **العربية** و**الإنجليزية**، مع فهم صوتي عميق للعامية المصرية والوقفات ونبرات الصوت وعلامات الترقيم (الفواصل، النقاط، علامات الاستفهام، والفقرات) بالاعتماد على **OpenRouter API** ونموذج **Google Gemini 2.5 Flash Lite** فائق السرعة والدقة.

---

## المميزات الرئيسية 🌟

1. **شريط التسجيل العائم بنمط Whisper Flow مع اختصار `Ctrl + Space`**:
   - اضغط **`Ctrl + Space`** في أي مكان بنظام ويندوز (أثناء تصفحك، كتابتك في Notepad، Word، البريد، أو المحادثات).
   - يظهر شريط عائم زجاجي مصغر (Floating Pill) في أسفل الشاشة مع وميض أحمر وموجات صوتية حية.
   - عند الانتهاء والضغط مجدداً على `Ctrl + Space`، يتم إيقاف التسجيل وتفريغ الصوت بذكاء ونسخ النص المفرغ فوراً إلى الحافظة (Clipboard) لتلصقه مباشرة (`Ctrl + V`).

2. **تسجيل صوتي نقي بتقنية 16kHz Mono PCM WAV**:
   - تسجيل مباشر من المايكروفون بدون أي تشويه وبدون ضغط WebM، لضمان أعلى درجات الوضوح الصوتي ونقاء الترددات التي تفضلها نماذج الذكاء الاصطناعي.

3. **فهم العامية المصرية والعربية الدارجة والوقفات والفواصل**:
   - يتعرف النموذج تلقائياً على اللهجة العامية ويكتب كل كلمة كما نُطقت (عايز، بيعمل، كده، علشان، مش، إيه... إلخ) بدون تحريف وبدون ترجمة.
   - **الوقفات القصيرة**: وضع فواصل عربية (`،`) أو إنجليزية (`,`).
   - **الوقفات التامة**: وضع نقطة (`.`) عند اكتمال المعنى.
   - **الوقفات الطويلة**: تقسيم الحديث إلى فقرات مستقلة ومريحة للقراءة تلقائياً.
   - **المصطلحات التقنية**: كتابة الكلمات الإنجليزية والتقنية بحروفها الإنجليزية بدقة.

4. **اعتماد نموذج Google Gemini 2.5 Flash Lite**:
   - نموذج خفيف وسريع جداً، اقتصادي التكلفة ومصمم للتعامل الفوري مع الصوت وفهم النبرات والوقفات.

5. **أدوات الإنتاجية والتحكم الكامل**:
   - لوحة تحكم كاملة (Dashboard) مع رسم بياني حي لموجات الصوت.
   - زر نسخ فوري، وتصدير النص كملف (`.txt`).
   - سجل داخلي (History) يحتفظ بالتسجيلات السابقة وتواريخها ومدتها.
   - أداة "تهذيب الفواصل" لإعادة تدقيق النصوص السابقة بنقرة واحدة.

## طريقة التشغيل (Quick Start)

### 1. المتطلبات:
- تثبيت [Node.js](https://nodejs.org) (الإصدار 18 أو أحدث).

### 2. التثبيت والتشغيل:
```bash
# تثبيت التبعيات (إذا لم تكن مثبتة)
npm install

# تشغيل التطبيق
npm start
```

### 3. إعداد مفتاح OpenRouter:
1. افتح التطبيق، وانقر على أيقونة **الإعدادات (⚙️)** في الزاوية العلوية.
2. ضع مفتاح الـ API الخاص بك من [openrouter.ai/keys](https://openrouter.ai/keys).
3. اضغط على **حفظ الإعدادات**.
4. جرب الآن الضغط على **`Ctrl + Space`** في أي مكان وتحدث بحرية!
